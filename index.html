People

Intake

Fill a person's assessment in one guided form instead of typing raw fields. Questions load privately from your data repo (intake_schema.json) — set ⚙ GitHub and ↻ Reload if they're missing. Save writes the answers into that person's fields; only the sections you actually fill are overwritten.

Careers

Library

Occupation-independent content — one shared set of fields, not tied to any person or career (e.g. the aggregated Capability Library built from every occupation's canon). Recipes whose subject or output is library read from and write to here.

Recipes

A recipe = a prompt body + which fields get appended under it + where the output is saved. Include an output field from an upstream recipe to chain steps.

Pipelines

A pipeline is an ordered list of recipes. Pick a subject once on the Generate tab, then step through: copy each prompt, paste its output, Save & next. Each step's output is saved before the next, so later steps automatically include earlier ones.
